## 🛠️ Technology Stack
- **Frontend Core**: React 18, Vite 6, Tailwind CSS
- **3D Graphics & WebGL**: Three.js, React Three Fiber (`@react-three/fiber`), Drei (`@react-three/drei`)
- **Animation Engine**: GSAP (GreenSock) ScrollTrigger, Framer Motion
- **Icons & UI**: Lucide React, Canvas Confetti

## 💻 Local Development

```bash
# Clone the repository
git clone https://github.com/madheshwarant-fullstack-dev/madheshwaran-portfolio.git
cd madheshwaran-portfolio

# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
